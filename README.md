## 一、公司简介

深圳天河智算科技有限公司（Shenzhen TianHeZhiSuan Technology Co., Ltd.）核心团队源自国防科技大学超算、智算与人工智能顶尖科研队伍，拥有大量项目落地实践经验与多年行业深耕积淀，掌握国际先进的超算、智算及人工智能技术研发与工程化应用能力。公司管理与市场运营团队成员多出身证券、银行、头部 IT 企业，具备成熟的企业治理与市场化运营经验。

公司依托五大国家级超级计算中心等顶尖算力底层平台，沉淀并行计算、人工智能领域核心技术，秉持「AI 赋能，万物智联」发展愿景，紧抓 AI 大模型产业落地发展机遇，依托软硬一体化性能优化技术，以超算技术与 AI 大模型技术为核心底座，面向万物智联、万物智造、万物智生场景，提供超算 / 智算算力服务、私有大模型技术产品、定制化应用系统开发等综合技术服务。

## 二、技术团队

创始技术团队承袭国防科技大学学术科研根基，在 BLAS 基础线性代数运算、FFT 稀疏线性方程组求解、AI 算子性能调优方向具备深厚技术积累。以天河超算原有骨干为基底，汇聚行业权威专家，搭建国内一流技术研发队伍，核心人员以博士学历为主，创始核心团队包含 **6 名博士、3 名硕士**。

### 技术成果

- **SAR 仿真**：性能实现两个量级提升。
- **OpenFOAM**：完成在飞腾芯片平台 **30% 性能优化**。
- **图计算**：项目包揽 **Graph500 四大榜单**。
- **行业影响**：相关成果入选 **湖南省 2022 年度十大科技新闻榜首**。

### 团队文化

天河团队赓续「胸怀祖国、团结协作、志在高峰、奋勇拼搏」的银河精神，肩负以科技驱动文明进步的使命，致力于打造世界一流的超级计算与人工智能产业技术服务商。
